## What it is

`gpui-markdown-editor` is a text editor view for [GPUI](https://www.gpui.rs) applications. People see formatted text while they type, with no `**` or `#` in sight. Your application still reads and writes plain Markdown files. It was written for [Sheaf](https://taulit.github.io/sheaf/), a notes app for GNOME, and is published as a separate crate so other GPUI apps can use it.

<CardGrid>
  <Card title="Lossless round-trip" icon="approve-check">
    Unedited blocks are written back byte for byte, including line endings, a BOM and front matter. This is tested against the CommonMark and GFM spec examples.
  </Card>
  <Card title="Input rules" icon="pencil">
    `# ` becomes a heading, `[] ` a checkbox and `**bold**` turns bold as you type. Backspace undoes the rule, and the whole thing can be turned off.
  </Card>
  <Card title="Tables and checklists" icon="list-format">
    GFM tables with cell editing, rectangle selection and resizable columns. Task lists use real checkboxes.
  </Card>
  <Card title="Fast on big files" icon="rocket">
    A keystroke plus its frame takes about 1.5 ms in a 10,000-block document. Opening 1 MB takes about 31 ms.
  </Card>
</CardGrid>

## Thirty seconds of code

```rust
let editor = cx.new(|cx| MarkdownEditor::new(window, cx, EditorOptions::default()));
editor.update(cx, |editor, cx| editor.set_markdown("# Hello\n\n- [ ] try it\n", cx));

cx.subscribe(&editor, |_, editor, event: &EditorEvent, cx| {
    if *event == EditorEvent::Changed {
        let markdown = editor.read(cx).markdown(); // save it, then `mark_saved`
    }
})
.detach();
```
